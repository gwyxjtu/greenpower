# 绿电直连微电网容量规划模型 (Green Power Microgrid Capacity Planning)

本项目为智能计算中心在绿电直连微电网规划阶段的投资容量优化模型。基于全年的时间序列进行运算（8760小时运行模拟），使用 Gurobi 求解器求得风电、光伏、储能与变压器的最佳装机规模。

## 文件结构简介

### 1. 理论数学模型
- **`green_power.tex`**
  理论模型的 LaTeX 源文件。严密地定义了微电网各组成部分的集合、设备与能源的物理运行约束方程式以及全局目标代价函数。所有的代码逻辑均严格映射此文件。

### 2. 优化驱动代码
- **`params.py`**
  **参数配置文件**。分离了全部的数值变量环境。
  - 集中管控所有静态标量输入，如：设备各类安装单价、市电电价参数、经济折扣与政策指标参数、储能系统的物联特征等。
  - 内置包含了用以支撑 8760h 线性规划的时间序列数据矩阵结构（负载时序图、风速光效因子时序、峰谷电价曲线等）。
  - *注：在此提供的是模拟占位数据合成逻辑，实际商业投测前请在此替换装载您正式的 CSV 业务序列数据集。*

- **`green_power_opt.py`**
  **核心寻优执行程序**。基于 `gurobipy` 构建的 MILP（混合整数线性规划）模型。
  - 读取上述参数后，它会在内部自动建立数学联系（处理跨时段储能 SOC 耦合推演、引入充放分离二元变量阻断死循环等）。
  - 直接执行即起动求解测试运算。

### 3. 数据分析输出 (程序自动生成)
- **`optimization_results.txt`**
  **宏观摘要报告单**。每次在主程序成功搜索到解（或被手动有效切断）后会生成并覆盖。这里沉淀了：年度最终决定部署的各模块 MW/MWh 级最优容量、总投资与运维花销占比的财务拆解项等宏观表现。

- **`timeseries_results.csv`**
  **微观运行明细表**。非常详尽的 8760 个节点的逐时记录集，用作验证模拟可行性和作图的底层数据流。记录了任意时间点（$t$）各设备的瞬时调度功率、储能系统的实时 SOC 水位线，以及微网是在向外电网输电还是索电。

## 运行方式 (Usage)

请确保环境内含有合法授权的 Python Gurobi 环境，使用如下指令开始求解：

```bash
python green_power_opt.py
```

> **实用提示**：完整的 8760 小时混合整数规划是一项巨大规模的工作计算（包含上万组二元变量分支）。代码内默认截断时间为 `5 分钟`（300s）。
> 如果您在使用中发现计算非常耗时，可通过按 `Ctrl+C` 发送中止信号，脚本依然会为您即时整理吐出当下记录的”可行域较优解（Feasible solution）“到上述那两个生成文件里供您先行考察。
